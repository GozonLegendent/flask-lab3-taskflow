# TaskFlow - Flask Lab Assignment 3

A task manager built with Flask and Python 3 (SQLite, CSRF protection, responsive UI with dark mode).

## Run

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 app.py
```

Open http://127.0.0.1:5000
